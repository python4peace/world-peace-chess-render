PUBLISHING — MANUAL, AFTER TESTING
From this new folder only, review:
  git status --short
  git diff --stat
Commit only these explicitly named files:
  git add -- templates/index.html templates/lesson.html static/theme.js static/unity-brand.css UNITY_BUILD_INFO.json UNITY_NEXT_STEPS.txt
  git commit -m "Rename site to Reuben World Peace Unity Chess and refine royal theme"
Publish a NEW branch, not main:
  git push -u origin reuben-unity-site
Then review a GitHub pull request from reuben-unity-site into main. If newer
main changes cause conflicts, STOP and resolve them deliberately. Do not force-push.
Keep Render Auto-Deploy disabled until you deliberately select the new commit.
The builder itself does not publish anything.
